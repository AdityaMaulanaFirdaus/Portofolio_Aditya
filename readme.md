# Aditya Portfolio

Website portofolio pribadi **Aditya Maulana Firdaus**, mahasiswa S1 Teknik Informatika Universitas Perjuangan Tasikmalaya. Proyek ini dibuat sebagai tugas mata kuliah **Web Programming**.

🔗 **Link:** [adityamaulanafirdaus.github.io/Portofolio_Aditya](https://adityamaulanafirdaus.github.io/Portofolio_Aditya/)

## Tentang Proyek

Website portofolio satu halaman (single page) yang memperkenalkan profil, keahlian, dan proyek saya. Proyek ini dibuat untuk mempraktikkan dasar-dasar pemrograman web: struktur halaman dengan HTML, desain tampilan dengan CSS, dan publikasi melalui GitHub Pages.

## Fitur

- **Navigasi** ke bagian Home, About, Skills, dan Projects
- **Hero section** berisi sapaan, deskripsi singkat, serta tombol *About Me* dan *Contact Me*
- **About Me**: profil singkat dan foto
- **Skills**: daftar keahlian
- **Projects**: daftar proyek yang pernah dikerjakan
- Tampilan modern dengan nuansa biru yang bersih dan mudah dibaca

## Teknologi yang Digunakan

- HTML5
- CSS3
- GitHub Pages (hosting)
